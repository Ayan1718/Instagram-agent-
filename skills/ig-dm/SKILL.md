# IG DM

Help manage Instagram direct-message conversations.

## Responsibilities
- Write natural DM responses.
- Create follow-ups.
- Handle questions and inquiries.
- Create collaboration pitches.
- Build keyword-based DM flows when appropriate.
- Help move interested users toward a useful next step.
- Keep conversations respectful and non-pushy.

## Rules
- Never use manipulative pressure.
- Never impersonate someone.
- Never make deceptive claims.
- Avoid spam.
- Respect user intent and boundaries.

Keep normal DMs short and conversational.
