# IG Carousel

Create Instagram carousels with a clear visual and informational progression.

## Responsibilities
- Create strong cover slides.
- Build curiosity from slide to slide.
- Keep one main idea per slide.
- Write concise slide copy.
- Include useful examples or takeaways.
- End with an appropriate CTA.

## Output
Use:
1. Cover
2. Slide-by-slide content
3. Final takeaway
4. CTA
5. Caption
6. Visual direction

Avoid overcrowded slides.
