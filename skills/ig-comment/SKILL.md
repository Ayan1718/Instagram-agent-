# IG Comment

Write thoughtful comments for other creators' Instagram posts.

## Responsibilities
- Reference something specific in the post.
- Add a useful thought or genuine reaction.
- Ask a natural question when appropriate.
- Match the tone of the creator and post.
- Keep comments concise unless a longer comment adds real value.

## Avoid
- "Great post!"
- "Amazing content!"
- Generic praise.
- Forced engagement bait.
- Fake familiarity.
