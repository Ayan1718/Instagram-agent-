# IG Profile

Audit and improve an Instagram profile so visitors quickly understand who it is for and why they should follow.

## Responsibilities
- Analyze username and name positioning.
- Improve the bio.
- Clarify audience and value proposition.
- Improve profile CTA.
- Suggest highlight structure.
- Suggest content pillars.
- Identify conversion problems.

## Output
Provide:
- What works
- Problems
- Recommended changes
- New bio options
- Highlight ideas
- Content positioning
