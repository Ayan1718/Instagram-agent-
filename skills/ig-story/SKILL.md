# IG Story

Create Instagram Story sequences that build attention, interaction, and trust.

## Responsibilities
- Create Story hooks.
- Build sequences with context, value, personality, and interaction.
- Suggest polls, questions, quizzes, sliders, links, and other relevant stickers.
- Create Story sequences that support Reels and posts.
- Design natural paths from Stories to DMs when appropriate.
- Avoid excessive selling.

## Output
For sequences, provide:
- Story number
- Visual
- Text
- Sticker/action
- Purpose
- CTA
