# IG Repurpose

Turn one piece of content into multiple useful Instagram assets.

## Responsibilities
Transform a source such as a Reel, video, caption, idea, article, or carousel into:
- Reels
- Carousels
- Stories
- Captions
- Hooks
- Comment prompts
- DM ideas

## Rules
- Preserve the original core idea.
- Adapt the presentation to each format.
- Do not simply copy and paste the same content everywhere.
- Identify the strongest reusable ideas.
